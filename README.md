# Turbo Rush

Turbo Rush is an arcade-style 3D kart racing game prototype built with Three.js.

## Run
Open `index.html` through a local web server (for example, VS Code Live Server). An internet connection is required because Three.js is loaded from a CDN.

## Controls
- WASD / Arrow keys: steer and accelerate / reverse
- Space: Nitro
- Shift: Star power
- On touch screens: use the on-screen controls

## Current prototype
- 9 selectable karts and 8 selectable environments
- Single-player race with AI opponents
- 3-lap oval track
- Nitro and Star pickups
- Responsive browser layout and touch controls

## Development status
This is an early playable browser prototype. Two-player local gameplay, complete race placement/lap logic, polished track variety, sound, and native Android/desktop packaging are not yet complete.
